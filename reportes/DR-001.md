# DR-001 — Defecto simulado en el checkout

## Resumen
El usuario intenta finalizar una compra desde la página de checkout, pero la aplicación muestra un mensaje de error al intentar continuar con el formulario vacío o con datos incompletos.

## Severidad
Media

## Reproducción
1. Iniciar sesión con `standard_user`.
2. Añadir un producto al carrito.
3. Ir a checkout.
4. Dejar en blanco el campo `First Name` o `Postal Code`.
5. Hacer clic en `Continue`.

## Resultado esperado
La aplicación debería mostrar el mensaje de validación correspondiente o permitir el flujo con datos correctos.

## Resultado actual
La aplicación no avanza y muestra un error de validación, lo que bloquea la compra con un formulario incompleto.

## Evidencia
- Se reproduce en la vista de checkout con la validación activa.
- El flujo se corta antes de llegar a la pantalla de resumen del pedido.

## Impacto
El usuario no puede completar la compra si el formulario tiene campos vacíos, lo que afecta la experiencia y la validación del proceso.

## Estado
Defecto simulado para la entrega de evidencias del curso de Playwright.
